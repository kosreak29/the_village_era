# ☕ The Village Era Cafe - Official Website

A modern, interactive, and premium fast-food cafe website built for **The Village Era**, located in Anjora, Durg, Chhattisgarh. This website is designed to give customers a "cafe vibe" digitally, featuring a warm aesthetic, glassmorphism UI, and direct WhatsApp ordering.

## ✨ Key Features
- **Modern UI/UX:** Warm coffee theme with glassmorphism (frosted glass) effects and neon highlights.
- **Direct WhatsApp Ordering:** Customers can order dishes directly via pre-filled WhatsApp messages with a single click.
- **Mood Matcher (Cravings):** A unique feature that recommends specific dishes based on what the user is craving (Spicy, Cheesy, or Relaxing).
- **Interactive Elements:** Custom glowing cursor, scroll-reveal animations, and a customized coffee-cup preloader.
- **Background Cafe Vibe:** Built-in soothing lofi music toggle for an immersive browsing experience.
- **Live Location:** Integrated Google Maps for easy navigation to the cafe.
- **Responsive Design:** 100% mobile-friendly and optimized for all screen sizes.

## 🛠️ Tech Stack Used
- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styling, animations, flexbox/grid layouts, and responsive media queries.
- **Vanilla JavaScript:** For interactivity, Intersection Observer (scroll animations), music toggle, and custom cursor logic.
